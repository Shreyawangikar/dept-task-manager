# Department Task Manager
(Mid mock -33282)

A web application for managing weekly lab tasks.

## Features
- User Registration (Student / Department)
- Login Authentication
- Department Dashboard (Create, Update, Delete Tasks)
- Student Dashboard (View Tasks Only)

## Tech Stack
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- JavaScript

## Run Locally

Install dependencies

npm install

Start server

node server.js

Open in browser

http://localhost:5000
